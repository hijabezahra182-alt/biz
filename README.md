# ✦ Lunora — Business Management Dashboard

A premium, responsive business management dashboard built with pure HTML, CSS, and JavaScript.

Lunora is designed as a modern SaaS-style business platform with a soft editorial aesthetic, combining ivory backgrounds, espresso tones, lavender accents, coral highlights, smooth interactions, and responsive layouts.

---

## ✨ Overview

Lunora is a frontend business management dashboard created to demonstrate how a complex business interface can be designed and developed without relying on frameworks or backend services.

The project includes multiple sections for managing business data, customers, products, orders, team members, analytics, reports, and application settings.

The goal was to create something that feels like a real-world SaaS product rather than a basic admin template.
